# Android Portfolio Website

A personal portfolio website designed to look and feel exactly like a modern Android mobile application.

## Features

- **Mobile-First Design**: Looks like a real Android phone on desktop.
- **Material Design**: Dark mode, rounded corners, ripple effects (simulated).
- **Smooth Transitions**: App-like screen navigation using Framer Motion.
- **Interactive Elements**: Bottom navigation, status bar, scrollable content.

## Tech Stack

- React (Vite)
- Framer Motion (Animations)
- Lucide React (Icons)
- Vanilla CSS (Styling)

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the link shown in the terminal (usually `http://localhost:5173`).
